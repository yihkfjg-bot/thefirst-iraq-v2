# سيرفر التحقق من الاشتراك — أوائل العراق

هذا سيرفر بسيط (Node.js + Express) يتحقق **فعليًا** من كون الطالب مشترك بقنوات التليجرام الثلاث قبل ما يفتح الجواب بالموقع. يستخدم Telegram Bot API + Telegram Login Widget، وين التحقق يصير بشكل حقيقي مو بس "زر أمانة".

---

## شلون تشتغل الفكرة (باختصار)

1. الطالب يضغط "سجّل دخول بتليجرام" بنافذة القفل.
2. تليجرام نفسه يتحقق من هويته ويرجع بياناته (id, hash...) موقّعة رقميًا.
3. المتصفح يرسل هالبيانات لسيرفرك.
4. السيرفر يتأكد إن التوقيع صحيح (يعني ما أحد زوّرها)، بعدين يسأل تليجرام مباشرة: "هذا اليوزر مشترك بالقناة الفلانية؟" عن طريق دالة `getChatMember`.
5. إذا مشترك بالثلاث قنوات → يفتح الجواب. إذا لا → يقوله شنو ناقصه بالضبط.

---

## المتطلبات قبل التشغيل

### ١. سوي بوت تليجرام
- افتح محادثة مع [@BotFather](https://t.me/BotFather) بتليجرام.
- أرسل `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ bot).
- راح يعطيك **توكن** (Token) — احتفظ فيه، هذا سري ما ينشر أبدًا.

### ٢. ضيف البوت للقنوات الثلاث كأدمن
البوت لازم يكون عضو/أدمن بكل قناة عشان يقدر يشوف مين مشترك:
- `@islamicwezary`
- `@FrancaisAA`
- `@basim_altmemy`

روح لكل قناة → إعدادات القناة → المدراء (Administrators) → أضف البوت.
(أبسط طريقة: خله أدمن بصلاحية "دعوة المستخدمين" بس، ما يحتاج صلاحيات نشر).

### ٣. اربط نطاق موقعك بالبوت (مطلوب لـ Login Widget)
Telegram Login Widget ما يشتغل إلا على نطاق (domain) مسجل مسبقًا:
- ارسل `/setdomain` لـ @BotFather.
- اختر بوتك، واكتب نطاق موقعك (لازم يكون HTTPS، مثال: `https://awael-iraq.com`).
- بدون هالخطوة، زر "تسجيل الدخول" ما يبين أو يرمي خطأ.

## التثبيت والتشغيل

```bash
cd awael-server
npm install
cp .env.example .env
```

افتح ملف `.env` وحط توكن البوت:
```
BOT_TOKEN=التوكن_الي_عطاك_ياه_BotFather
PORT=3000
```

شغّل السيرفر:
```bash
npm start
```

افتح `http://localhost:3000` بالمتصفح — الموقع نفسه يطلعلك (لأن السيرفر يقدم ملفات `public/` تلقائيًا).

## لوحة التحكم (Dashboard) — إدارة المحتوى بدون كود

صار عندك لوحة تحكم على `/admin` تقدر منها تضيف/تعدّل/تحذف المواد والأقسام العامة وأسئلتها وأجوبتها، بدون ما تحتاج تعدل بالكود أو ترسلي المحتوى.

### كيف تفتحها
1. تأكد `ADMIN_PASSWORD` محدد بملف `.env` (شوف قسم "التثبيت والتشغيل" فوك).
2. افتح `http://localhost:3000/admin` (أو نطاقك بعد الرفع).
3. دخل كلمة السر.

### شلون تشتغل
- كل مادة أو موضوع فيه حقوله (الاسم، الأيقونة/الصورة، التصنيف) + قائمة أسئلة وأجوبة تقدر تضيف/تحذف منها بحرية.
- زر **"حفظ التغييرات"** فوق يحفظ كل شي دفعة وحدة بملف `data.json` بالسيرفر.
- أي تغيير تحفظه يطلع فورًا بالموقع العام — الصفحة الرئيسية تجيب المحتوى من السيرفر كل ما تنفتح.
- لو ما ضغطت "حفظ"، التعديلات تضيع إذا سكرت الصفحة — احفظ بانتظام.

### ملاحظات أمان
- الدخول بكلمة سر وحدة بسيطة (Header)، مناسب لشخص أو فريق صغير موثوق يدير المحتوى — مو نظام صلاحيات متعدد المستخدمين.
- **لا تشارك رابط `/admin` أو كلمة السر مع أي حد غير موثوق** — أي شخص عنده كلمة السر يقدر يعدل أو يحذف كل محتوى الموقع.
- غيّر `ADMIN_PASSWORD` الافتراضي بـ `.env` لكلمة قوية قبل النشر.

## خطوة أخيرة لازم تسويها بالكود

بملف `public/index.html`، دوّر على هذا السطر:

```js
s.setAttribute('data-telegram-login', 'YOUR_BOT_USERNAME');
```

وبدّل `YOUR_BOT_USERNAME` باسم يوزر بوتك الحقيقي (بدون @).

## رفع الموقع أونلاين (Deployment)

هذا السيرفر لازم يشتغل على نطاق HTTPS حقيقي (مو ملف HTML لحاله على جهازك) عشان:
- Telegram Login Widget يشتغل بس على نطاق مسجل بـ `/setdomain`.
- المتصفح يقدر يوصل لـ `/api/check-subscription`.

خيارات سهلة للرفع: Render، Railway، أو أي VPS عادي. الخطوات العامة:
1. ارفع مجلد `awael-server` كامل (بدون `.env` — حطه بإعدادات الاستضافة كـ Environment Variable).
2. تأكد المنصة تدعم Node.js ≥ 18 (نستخدم `fetch` المدمج بالسيرفر).
3. بعد الرفع، سوي `/setdomain` بـ BotFather بنفس نطاق الاستضافة.
